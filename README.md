<p align="center">
Matterworks lets you recycle almost any item into universal Matter, then use it to reconstruct useful resources.
</p>

<p align="center">
Matterworks is a NeoForge mod for Minecraft that adds a Matter-based recycling and reconstruction system.
</p>

<p align="center">
The project is designed to give unwanted items a new purpose and reduce item clutter in survival worlds and modpacks.
</p>

<p align="center">
<img src="https://raw.githubusercontent.com/IntelligenceModding/Matterworks/refs/heads/assets/Compatibility.png" height="75">
</p>

Matterworks is built for:

* **Minecraft:** 1.21.1
* **Mod Loader:** NeoForge

The mod is designed with modpacks in mind and aims to work well in both Vanilla+ and larger kitchen-sink style packs.

Planned compatibility goals include:

* Datapack support
* Configurable Matter values
* Modpack balancing options
* JEI / EMI support
* Automation support
* KubeJS support

Not all planned compatibility features may be available in the current version.

<p align="center">
<img src="https://raw.githubusercontent.com/IntelligenceModding/Matterworks/refs/heads/assets/Features.png" height="75">
</p>

Matterworks currently focuses on a simple resource loop:

* Recycle unwanted items into Matter.
* Process Matter into a more useful form.
* Use Matter to reconstruct useful resources.
* Analyze items before reconstruction where required.

The goal is to keep the system useful without adding a giant tech progression, energy network, or complicated machine chain.
